IPScans LPR Pro Preview 0.5.0.dev4

Development evaluation build. This package is not digitally signed and is not a production release.
The installer includes the Python and Qt runtime; no separate Python/Node.js installation is required.
The preview installs for the current Windows user and creates Start menu and optional desktop shortcuts.
Starting at Windows sign-in is optional and disabled by default.

Camera credentials and records stay in the Windows user's local IPScans/LPR Pro data folder.
Upgrading or uninstalling the application does not delete that data folder.
Back up existing records from the application before evaluating a new version.

Recognition models are separate evaluation downloads. Model/data commercial distribution review,
field OCR accuracy qualification, signed updates and clean-machine qualification remain pending.
Physical barrier control is not provided.
