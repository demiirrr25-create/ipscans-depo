# IPCast 2.6.0

The desktop client has been updated to align with the unified IPScans Design System. The interface features a pure black `#000000` canvas, high-contrast typography, controlled greys, and refined interactive states.

## Added & Improved

- Unified IPScans design tokens for all client views, dialogs, connection bars, device lists, and session toolbars.
- Pure black presentation and high-contrast typography conforming to the ecosystem design standards.
- Refined window styling and welcome experience alignment.
- Removed decorative legacy branding markers and standardized layout structures.

## Validation

- Verified unit and integration test coverage across network, security, and remote desktop services.
- PowerShell workflow syntax and release publish gates verified.
- Client build definitions aligned with the release management pipeline.
