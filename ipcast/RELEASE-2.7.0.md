# IPCast 2.7.0

IPCast 2.7.0 brings the unified IPScans v2 Design System and a complete Light Mode, Dark Mode, and OS-aware theme engine across the entire Windows desktop client.

## Added & Improved

- Complete Light Mode (`#FFFFFF` / `#F8F9FA` surfaces, `#0B0D12` ink, `#2F6BFF` Signal Blue) and Dark Mode (`#07080B` / `#0D0F14` surfaces, `#F5F7FA` ink, `#4C82FF` Signal Blue) token architecture matching IPScans.com.
- Instant Sun/Moon theme toggle button in the top navigation bar with persistent preference storage and automatic Windows OS theme detection.
- Unified card radii, pill controls, hairline borders, and high-DPI responsive scaling across the main workspace, remote screen viewer, file manager, session chat, incoming connection dialog, and tunnel manager.

## Validation

- Verified 153 unit and integration tests across network, security, and remote desktop services.
- Verified automated UI smoke tests (`IPCast.UiSmoke`) across Light Mode, Dark Mode, and workspace views.
- Verified self-contained Windows x64 portable executable and Inno Setup installer.
