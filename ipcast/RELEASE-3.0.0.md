# IPCast 3.0.0 — Native Rust Release Notes

IPCast 3.0.0 migrates the entire remote desktop, LAN discovery, and file transfer engine to **100% Native Rust (`IPCast-3.0.0.exe` & `IPCast-3.0.0-Setup.exe`)**, reducing the standalone binary footprint from ~71 MB to **~2.7 MB** with instant startup and the IPScans v2 Light/Dark design system.
