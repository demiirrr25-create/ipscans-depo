# IPScans+ 4.3.0

Right-click a device in Network Map or the device list and choose Rename; F2 works too. Names are stored locally, scoped to the network. Known MAC addresses retain their label after an IP change. An empty name restores the discovered identity. Double-click still opens the device web interface in the default browser.

Export report now defaults to PDF. Reports include custom names, IP/MAC addresses, vendor, device type and discovered TCP ports. Headers repeat on every page, long observations continue across pages, and filtered views export only the visible devices. Saving is atomic; failures are reported without replacing an existing report with a partial file. HTML, CSV and JSON remain available.

The installer retains versioned executable paths and is tested against an open 4.2.0 installation, same-version repair, shortcuts and uninstall. Custom names are user metadata and do not change device network settings.
